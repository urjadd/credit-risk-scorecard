# Credit Risk Scorecard

An end-to-end credit risk scoring system built on the Home Credit Default Risk dataset (300K+ real loan applications). Logistic regression scorecard with WOE encoding, SHAP explainability, FastAPI backend, Groq LLM explanations, and a live Streamlit dashboard.

## Live Demo

* Dashboard: [Streamlit App](https://your-streamlit-url-here.streamlit.app/)
* API: https://credit-risk-scorecard-1.onrender.com/docs

## What This Does

A loan officer enters applicant details and gets back a credit score (300-900), risk band (LOW / MEDIUM / HIGH), the top 3 factors driving the decision, and a plain English explanation generated by an LLM. Designed for credit decisioning, not Kaggle leaderboards.

## How It Works

1. Raw applicant data comes in through the API or dashboard
2. WOE (Weight of Evidence) encoding transforms features into log-odds
3. Logistic regression predicts probability of default
4. Probability converts to a 300-900 credit score using scorecard parameters
5. SHAP values identify the top factors driving the decision
6. Groq LLM generates a plain English explanation for the loan officer

## Key Design Decisions

**Logistic regression over XGBoost.** Banks and regulators require interpretable models for credit decisioning. Logistic regression provides monotonic feature relationships and coefficient-level explainability that XGBoost cannot.

**WOE encoding over one-hot.** Weight of Evidence transforms categorical variables into log-odds of default, making them directly compatible with logistic regression and providing built-in handling of missing values.

**Single table (`application_train.csv`).** Supplementary tables in the Home Credit dataset improve Kaggle leaderboard scores but add complexity without teaching core credit risk concepts. The focus is on the scorecard methodology, not competition ranking.

**Deterministic reason codes before LLM.** The explainer generates structured reason codes from SHAP values first, then passes them to the LLM. If the LLM fails, the reason codes still work. No single point of failure.
